# Mathematical Models and Assumptions

All parameter values are illustrative and are shared between the Python and
MATLAB implementations where applicable. These are educational models, not
validated device specifications.

## 1. Fiber optic isolator

### Basic power model

For input power \(P_\mathrm{in}\), insertion loss \(IL\), and reverse isolation
\(ISO\), both expressed in dB:

\[
P_f=P_\mathrm{in}10^{-IL/10},\qquad
P_r=P_\mathrm{in}10^{-ISO/10}.
\]

The demonstration uses \(P_\mathrm{in}=10\) mW, \(IL=0.5\) dB, and
\(ISO=30\) dB. Thus \(P_f\approx8.9125\) mW and \(P_r=0.01\) mW. Here, `ISO`
is reverse attenuation relative to input; the forward-to-reverse contrast is
therefore \(ISO-IL=29.5\) dB.

### Jones model

An ideal linear polarizer at angle \(\theta\) projects onto
\[
\mathbf{p}(\theta)=(\cos\theta,\sin\theta)^T,
\]
and a linear polarization rotation is
\[
R(\phi)=
\begin{bmatrix}\cos\phi&-\sin\phi\\\sin\phi&\cos\phi\end{bmatrix}.
\]
The Faraday angle is \(\phi=VBL\), where \(V\) is the Verdet constant,
\(B\) is the longitudinal magnetic field, and \(L\) is the interaction length.
In this simplified model its signed rotation is the same in both propagation
directions. The input polarizer is at 0 degrees, the Faraday angle is 45 degrees,
and the output analyzer is at 45 degrees. Malus' law gives normalized forward
power \(1\) and reverse power \(0\) for the ideal angles.

The model omits finite polarizer extinction, wavelength dependence, reflections,
temperature effects, and insertion loss. A real device has finite reverse
transmission.

## 2. Three-port circulator

The ideal power-routing matrix (rows are output ports, columns are input ports)
is
\[
T_\mathrm{ideal}=
\begin{bmatrix}
0&0&1\\1&0&0\\0&1&0
\end{bmatrix}.
\]
The routed power is multiplied by \(10^{-IL/10}\); each unwanted output is
assigned \(10^{-ISO/10}\). The example uses \(IL=0.6\) dB and \(ISO=35\) dB.
This simple transfer matrix is not a unitary scattering matrix because it
represents absorption, isolation, and omitted ports without modeling them
explicitly. It also does not model birefringent crystals or magneto-optic
components individually.

## 3. Four-channel WDM

Channels are centered at wavelengths \([1530,1540,1550,1560]\) nm, with
\(f_i=c/\lambda_i\). A sampled complex envelope per channel is
\[
E_i(t)=e^{j2\pi(f_i-f_\mathrm{ref})t}
       [1+0.25\cos(2\pi f_m t)],
\]
with \(f_m=18\) GHz. The multiplexer sums the envelopes. The fiber applies
power attenuation \(\alpha=0.2\) dB/km and second-order chromatic dispersion:
\[
E_\mathrm{out}(t)=
\mathcal{F}^{-1}\{ \mathcal{F}[E_\mathrm{in}(t)]H(f)\}
10^{-\alpha L/20},
\qquad
H(f)=e^{-j2\pi^2\beta_2Lf^2}.
\]
Here \(\beta_2=-21.7\) ps²/km, \(L=50\) km, and the factor multiplying the
field converts power loss in dB to field amplitude. Demultiplexing uses ideal,
non-overlapping rectangular masks around each channel center. This isolates the
chosen envelopes but does not model practical filter roll-off or crosstalk.

This narrow educational model excludes ASE noise, nonlinear effects, PMD,
laser linewidth, coding, receiver noise, and detailed modulation formats.
Sampling is applied to complex envelopes and is not a literal simulation of
the optical carrier oscillation.

## Shared assumptions

- All plotted power values are normalized simulation results unless a unit is
  explicitly stated.
- The default channel wavelengths are illustrative, not a claim of compliance
  with a particular ITU grid.
- Results are generated by deterministic equations; no experimental data are
  used.
