FIBER OPTIC SIMULATION PROJECT
RUN INSTRUCTIONS AND OUTPUT GUIDE
=================================

PROJECT FOLDER
--------------
Open PowerShell or the VS Code terminal in the project root folder.


PYTHON: FIRST-TIME SETUP (WINDOWS)
---------------------------------
Create a virtual environment:

    python -m venv .venv

Install the project's Python libraries:

    .\.venv\Scripts\python.exe -m pip install -r Python\requirements.txt

The project uses NumPy, Matplotlib, and Pillow. No global installation is
required.


RUN ALL PYTHON SIMULATIONS
--------------------------
From the project root, run:

    .\.venv\Scripts\python.exe -m Python.main

The command runs the isolator, circulator, and WDM models. It recreates the
plots, animations, and CSV result files in Results.

Before running, it asks for parameters. Press Enter to accept each displayed
default:

    Isolator: input power, insertion loss, reverse isolation,
              input polarizer angle, Faraday rotation, analyzer angle
    Circulator: input power per port, routed insertion loss,
                unwanted-port attenuation (circulator stays three-port)
    WDM: channel count, wavelength for every channel, fiber length,
         attenuation per km, beta2 dispersion, modulation frequency

WDM wavelengths must be unique and positive. The simulation checks that the
requested wavelengths and modulation fit its sampling and channel-filter
bandwidth; if they do not, it asks for the WDM settings again.

To run one model only:

    .\.venv\Scripts\python.exe -m Python.isolator.isolator_simulation
    .\.venv\Scripts\python.exe -m Python.circulator.circulator_simulation
    .\.venv\Scripts\python.exe -m Python.wdm.wdm_simulation

The individual model modules run with their example defaults. Use the all-model
entry point above to enter custom values interactively.


RUN PYTHON TESTS
----------------
From the project root:

    .\.venv\Scripts\python.exe -m unittest discover -s Python\tests -v

Verified result: all 13 tests pass.

MATLAB
------
Open MATLAB with its current folder set to the project root, then run:

    run('MATLAB/run_all.m')

The scripts are under MATLAB\Isolator, MATLAB\Circulator, and MATLAB\WDM.
They use base MATLAB features and are intended to create MATLAB-specific
plots, GIFs, and a WDM CSV in the same Results folders. MATLAB/Octave was
not installed in the environment where this project was last run, so MATLAB
execution and its outputs have not been verified there.
The MATLAB entry point asks for the equivalent values and accepts defaults
when Enter is pressed. It supports a user-selected WDM channel count and
wavelengths; the circulator remains three-port.


MODEL LIMITATIONS
-----------------
These are educational simulations, not experimentally validated component
models or commercial link predictions. The Jones isolator is idealized; the
circulator is represented by a phenomenological transfer matrix; the WDM model
omits noise, nonlinear effects, and practical filter and receiver behavior.
See Documentation\Mathematical_Models.md for equations and assumptions.
